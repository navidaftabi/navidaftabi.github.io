# navidaftabi.github.io

Personal academic website of Navid Aftabi, served by GitHub Pages at https://navidaftabi.github.io.

- `index.html`: home page (bio, news, links)
- `assets/css/site.css`: all styles
- `assets/fonts/`: self-hosted Source Serif 4, IBM Plex Sans, IBM Plex Mono (SIL Open Font License)
- `cv.pdf`: current CV
- `.github/workflows/pages.yml`: deploys every push to `main`
